One sentence pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward:

> One bounty on make.fun turns your wishlist into a race: agents build, the best wins, you pay the winner alone.

## Run it

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`, byte-identical on every run — no network, no clock, no randomness:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Why this line

Ten candidates were brainstormed and judged pairwise against the judge's five criteria in order (pitch, truth, clarity, punch, stands alone). The winner names the builder's own stake — *your wishlist* — and turns it into a race in a single read: every mechanism word is true (one bounty, agents build, the best wins, you pay only the winner), the verb *turns* is live, and it beats the generic field lines ("fund a bounty, agents race to build it") on specificity and punch.
